Match each Vercel preview deployment to its Supabase preview branch, so every preview runs against the right database schema, Edge Functions, and other Supabase configuration.

Use this guide when you already get a Supabase preview branch for each pull request, and your frontend deploys a Vercel preview for each pull request too. Without this integration, those previews use the Supabase URL and keys set on your Vercel project, which usually point at your production project. A preview built to test a schema change then reads and writes production data.

If you don't have preview branches yet, start with [Branching](/docs/guides/deployment/branching). To manage Supabase projects from your Vercel account instead, see [Vercel Marketplace](/docs/guides/integrations/vercel-marketplace).

## Prerequisites

Before you connect Vercel, set up the following:

- Set up [branching](/docs/guides/deployment/branching) on your Supabase project.
- Install the [Vercel GitHub integration](https://vercel.com/docs/deployments/git/vercel-for-github) on your Vercel project.

## Connect Vercel

To connect Vercel to your Supabase project:

1. Install the Supabase integration from the [Vercel marketplace](https://vercel.com/integrations/supabase), or click the blue **Deploy** button in a Supabase example app's `README` file.
2. On your organization's [**Integrations**](/dashboard/org/_/integrations) page in the Supabase Dashboard, connect your Supabase project to your Vercel project.

## After you connect

Supabase updates your Vercel project with the environment variables for each preview branch. It syncs them when a pull request opens, not when the branch is created.

The integration depends on Vercel preview deployments, so Vercel can start a deployment before Supabase sets the variables. Supabase always redeploys the most recent deployment of the pull request to cover this.

To let users sign in on a preview deployment, add its URL to your redirect allow list. For the wildcard pattern, see [Vercel preview URLs](/docs/guides/auth/redirect-urls#vercel-preview-urls).
